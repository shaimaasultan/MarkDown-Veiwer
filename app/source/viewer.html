About Markdown Viewer

Created by Shaimaa Soltan

🔒 Preview only. Markdown files are displayed, never executed: scripts, on…= event handlers, javascript: links, frames, forms and plugins in a document are removed before display and also blocked by the browser's security policy.

Libraries

All bundled with the app (inside its signed MarkdownViewerWebView2.Content.dll) — nothing is loaded from the internet, so math, code colouring and diagrams always work.

Source → viewed breakdown


Why the text on screen is shorter than the file: formatting symbols and layout lines are removed (−), and a few things are added (+, e.g. a line break shown as a space). Characters include spaces but not line breaks; viewed lines are non-empty lines; viewed words are the readable text (code blocks, equations and diagram labels are shown but not counted as words). Any residual is listed as rendered text outside the Markdown model.
